## 📖 О проекте

**GoodCube** — это уникальный Minecraft сервер, созданный для тех, кто ценит качественный геймплей, дружелюбное сообщество и постоянное развитие. Мы предлагаем игрокам:

- 🎮 **Стабильный сервер** с минимальными лагами
- 👥 **Дружелюбное сообщество** и активную поддержку
- 💎 **Уникальную систему привилегий** и доната
- 🏆 **Интересные ивенты** и конкурсы
- 🔧 **Качественную модерацию** и защиту от читеров

## 📋 Правила сервера

Основные правила:

1. **Уважайте других игроков** — никаких оскорблений и токсичности
2. **Не используйте читы** — Xray, килл-аура и другие моды запрещены
3. **Не гриферьте** — чужое имущество неприкосновенно
4. **Не спамьте** — не засоряйте чат
5. **Соблюдайте PvP правила** — никаких убийств на спавне

📖 **Полный список правил** доступен на [странице правил](https://goodcube.github.io/rules.html)
